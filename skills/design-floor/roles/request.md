# Lane `request` — what someone typed into the window

You are probably not reading this. No agent is dispatched to this lane.

It carries what a person types into the floor's request box: a sentence in
words, turned into a plan, refused or accepted by the validator, and built
through this lane so the SKILL it sends lands in the transcript beside
everyone else's. A request is a participant on this floor, not a side door —
if it draws something, you can see exactly what it drew and what came back.

## What it owns

Whatever cell the request names, which is usually `DEMO/CELL` or whatever
library and cell the words mention. Agents on other lanes own named cells and
should not assume this one leaves theirs alone: if you need a cell that a
request might also touch, read it back before relying on it.

## Report

None. There is nobody to report to — the answer goes back to the window that
asked, and it is read out of the design database rather than echoed from the
plan.
